# Метрики дашборда

## Как считались метрики

| Метрика | Формула | Способ в Superset |
|---------|---------|-------------------|
| DAU | `COUNT(DISTINCT user_id)` за день | Big Number + агрегация |
| CTR | `countIf(user_id, action = 'click') / countIf(user_id, action = 'view')` за день | Big Number + агрегация |
| Количество действий на пользователя | `COUNT(*) / COUNT(DISTINCT user_id)` за день | Big Number + агрегация |
| Retention | SQL query | Кастомный запрос (см. `retention.sql`) |

## Что за метрики

### DAU (Daily Active Users)
Количество уникальных пользователей, совершивших любое действие за день.

### CTR (Click-Through Rate)
Доля пользователей, которые кликнули на пост, от тех, кто его увидел.

### Количество действий на пользователя
Среднее количество действий, которое совершает один пользователь за период. Показывает глубину вовлечения.

### Retention
Доля пользователей, вернувшихся в продукт на N-й день после первого визита. Ключевая метрика удержания.
